# Hugin Bridge

> Cross-chain bridge powered by the Hugin messaging network

## Features

- Multi-chain bridge support for Kryptokrona ecosystem
- Fast P2P messaging via Hugin network
- End-to-end encrypted communications
- Decentralized relay architecture
- Real-time operation monitoring

## Quick Start

```bash
git clone https://github.com/kryptokrona/hugin-bridge.git
cd hugin-bridge
gradle build
gradle run
```

## Configuration

```properties
hugin.network=mainnet
bridge.port=8080
node.rpc=http://localhost:13000
```
